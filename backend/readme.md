# FMap Playground
Analysis tool for visualizing neural network computation flows along with intermediate feature maps.

---

## Install

### Backend
```shell
poetry shell
poetry install
```

Install Graphviz with brew:
- default `brew install graphviz`
- arm `arch -arm64 brew install graphviz`

### Frontend
```shell
cd frontend
npm install
```

---

## Run
```shell
pyhton api.py
```
```shell
cd frontend
npm run dev
```
